# 🐊 GatorVault Brand Usage Guidelines

These guidelines ensure consistent, premium, and recognizable use of the GatorVault identity across all platforms.

---

# 1. Logos

## Primary Wordmark

- Use on light or dark backgrounds.
- Minimum width: **160px**
- Do not stretch, warp, or recolor.
- Orange underline must remain intact.

## GV Monogram

- Use for:
  - App icons
  - Favicons
  - Sidebar icons
  - Social avatars
- Minimum size: **48×48px**

## Insider Badges

- 5-level system:
  - Rookie → Loyalist → Insider → Elite → Legend
- Never recolor badges.
- Use only for authenticated members.

---

# 2. Color System

## Primary Colors

- Gator Blue `#0021A5`
- Gator Orange `#FA4616`
- Swamp Navy `#0A0F1A`
- White `#FFFFFF`

## Secondary Colors

- Swamp Green `#1C3F2C`
- Storm Gray `#A7B0C0`
- Fog Gray `#E5E7EB`

## Utility Colors

- Success Green `#16A34A`
- Warning Yellow `#FACC15`
- Error Red `#DC2626`
- Heatmap Green `#4ADE80`
- Heatmap Red `#FF4D4D`

Never introduce off-brand colors.

---

# 3. Typography

## Font Family

**Inter** (Bold, SemiBold, Regular, ExtraBold)

## Usage

- H1: Inter Bold 32–40px  
- H2: Inter Bold 24–28px  
- H3: Inter SemiBold 18–20px  
- Body: Inter Regular 14–16px  
- Numbers: Inter ExtraBold 32–48px  
- Ticker: Inter SemiBold 14px  

Never substitute fonts.

---

# 4. Gradients & Textures

## Approved Gradients

- Swamp Night  
- Blue Glow  
- Orange Fireline  
- Momentum Meter (orange → yellow)

## Approved Textures

- Stadium Lights (bokeh)
- Swamp Mist
- Turf Stripe

Textures must be subtle (opacity 10–25%).

CSS classes: `.gv-texture-stadium-lights`, `.gv-texture-swamp-mist`, `.gv-texture-turf`

---

# 5. UI Components

Use the `.gv-*` classes defined in `gatorvault-brand.css`:

- `.gv-btn--primary`
- `.gv-card`
- `.gv-stat-card`
- `.gv-badge--commit`
- `.gv-tab-bar`
- `.gv-type-h1` through `.gv-type-number`

Never hardcode colors or typography.

---

# 6. Do & Don't

### ✔ Do

- Use brand tokens
- Maintain spacing and hierarchy
- Use approved textures
- Keep UI clean and premium

### ✖ Don't

- Add drop shadows to logos
- Use unapproved colors
- Modify badge colors
- Stretch or distort logos
