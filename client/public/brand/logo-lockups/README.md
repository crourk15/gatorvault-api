# 🐊 GatorVault Logo Lockups

Official rules for combining logos with text, badges, and backgrounds.

Reference SVGs in this folder demonstrate approved compositions.  
Do not alter spacing ratios when scaling.

---

## 1. Horizontal Lockup

```
[GatorVault Wordmark]                    [GV Monogram]
```

- Wordmark left-aligned
- Monogram right-aligned in the same row
- Minimum gap: **24px**
- File: `horizontal-lockup.svg`

---

## 2. Vertical Lockup

```
        [GV Monogram]
   [GatorVault Wordmark]
```

- Monogram centered above wordmark
- Vertical gap: **16px**
- File: `vertical-lockup.svg`

---

## 3. Badge Lockup

```
     [Insider Badge Level X]
      [GatorVault Wordmark]
```

- Badge centered above wordmark
- Use member's authenticated badge level only
- Gap: **12px**
- File: `badge-lockup.svg`

---

## 4. Dark Mode Lockup

- Wordmark: **white** text, orange underline unchanged
- Monogram: white fill with orange stroke accent
- Badge: unchanged (use official SVG)

---

## 5. Light Mode Lockup

- Wordmark: **Gator Blue** `#0021A5`
- Monogram: Blue fill with orange stroke
- Background: White or Fog Gray `#E5E7EB`

---

## 6. Social Lockup

- Square format (1:1)
- Monogram centered
- Wordmark optional below (max width 80% of canvas)
- Minimum canvas: **400×400px**
- File: `social-square-lockup.svg`

---

## Minimum sizes

| Asset | Minimum |
|-------|---------|
| Wordmark | 160px wide |
| Monogram | 48×48px |
| Badge | 48×48px |
