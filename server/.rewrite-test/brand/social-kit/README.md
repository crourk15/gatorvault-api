## E. Social Badges

### "Insider" Badge

- Use **Level 3** badge (`/brand/badges/badge-level-3.svg`)
- Add **INSIDER** text below in Inter Bold
- File: `badge-insider-label.svg`

### "Elite Insider" Badge

- Use **Level 4** badge (`/brand/badges/badge-level-4.svg`)
- Gold glow on export (`#D4AF37` at 20% outer glow)
- File: `badge-elite-insider.svg`

### "Legend" Badge

- Use **Level 5** badge (`/brand/badges/badge-level-5.svg`)
- Diamond sparkle accent permitted on marketing only
- File: `badge-legend.svg`

---

## Export checklist

1. Open SVG in Figma, Illustrator, or Inkscape
2. Export at exact platform dimensions (PNG or JPG)
3. Verify safe areas on mobile crop previews
4. Do not recolor logos or badges
