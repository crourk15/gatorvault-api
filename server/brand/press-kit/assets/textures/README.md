# Texture PNG exports

Subtle overlays for marketing comps (10–25% opacity).

| File | Description |
|------|-------------|
| `stadium-lights.png` | Bokeh / stadium lights |
| `swamp-mist.png` | Swamp mist gradient |
| `turf-stripe.png` | Turf stripe pattern |

Web CSS equivalents: `.gv-texture-stadium-lights`, `.gv-texture-swamp-mist`, `.gv-texture-turf`
