# 🐊 GatorVault Insider Badges

GatorVault uses a 5-level Insider badge system to recognize member tenure and engagement.

## Levels

1. **Swamp Rookie**
   - 0–30 days
   - Badge: Level 1 (blue circle, baby gator)

2. **Gator Loyalist**
   - 30–90 days
   - Badge: Level 2 (orange shield)

3. **Insider**
   - 90–180 days
   - Badge: Level 3 (blue/orange flame)

4. **Elite Insider**
   - 180–365 days
   - Badge: Level 4 (gold gator head)

5. **The Swamp Legend**
   - 365+ days
   - Badge: Level 5 (diamond crest)

## Usage

- Display in member profile header.
- Show next to username in community threads.
- Never recolor or modify badges.
- Badge level is determined server-side (tenure + plan).
