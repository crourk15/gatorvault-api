# GatorVault UI Components

Component library lives in **`client/lib/gatorvault-brand.css`**.

## Buttons

| Class | Use |
|-------|-----|
| `.gv-btn.gv-btn--primary` | Primary actions |
| `.gv-btn.gv-btn--secondary` | Outlined actions |
| `.gv-btn.gv-btn--danger` | Destructive actions |

## Cards

| Class | Use |
|-------|-----|
| `.gv-card` | Standard dark card |
| `.gv-stat-card` | Large-number recruiting stats |

## Badges

| Class | Use |
|-------|-----|
| `.gv-badge--commit` | Commit events |
| `.gv-badge--trending` | Trending intel |
| `.gv-badge--new` | New alerts |

## Tabs

- `.gv-tab-bar` — container
- `.gv-tab.is-active` — active tab with orange underline

## Typography

- `.gv-type-h1` … `.gv-type-h3`
- `.gv-type-body`, `.gv-type-label`, `.gv-type-number`, `.gv-type-ticker`
