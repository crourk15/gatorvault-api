# PART B — MONEY PLAY SETUPS (DO THESE EVERY SNAP)

These are the “no question” competitive setups creators are running. Basic stock routes lose to good users — these setups are why.

## B1. Cross Wheels — Gun Tight Doubles (ZONE / MATCH DESTROYER)
```
ALIGNMENT: RB + TE to WIDE side of field
HOT ROUTE: Streak the short-side inside slot (short-side Square/X typically)

READ ORDER: X (wheel) → A (TE drag/check) → B (middle sit)

COVER 3: no hard flat on wheel → throw wheel 5–10. Curl flats → still wheel.
COVER 2: cloud flats do NOT take wheel → throw wheel 5–10.
SHADE DOWN: wait, then hit wheel UP the sideline 15–25.
MATCH / COVER 4: combo breaks match — free 10–15 in the void.

IF WHEEL TAKEN: check TE / A over middle. Both taken + shade down → B middle.
```

## B2. Shot Fake Cross — Gun Tight Doubles (MAN DESTROYER)
```
ALIGNMENT: RB + TE to WIDE side
HOT ROUTE: Drag the tight end

COVER 1: WR crosser opens easy
COVER 2 MAN: B + TE both live → take open for 10–15
COVER 0 / MUG: RB+TE already help block — TE or B comes open FAST. Ball out.

Do NOT hold. Man windows die if you admire the route.
```

## B3. Verticals — Gun Trips TE / Flex (UNIVERSAL)
```
ALIGNMENT: Trips to WIDE side
HOT ROUTES:
  - RB → Texas route
  - Outside trips WR → Comeback (optional vs soft zone)

COVER 3: first read = quick SEAM to middle trips (Y) 10–15. Shade down → even faster.
ZONE RULE: read yellow hook/curls
  - They sink → Texas underneath
  - They bite → comeback OR deep post/seam
COVER 2: hook/curl sinks → Texas; bites → inside trips = shot play
MAN: Texas RB first; press + shade under → outside shot possible
BLITZ EXPECTED: keep RB blocking instead of Texas
COVER 0 + BLOCKED: B receiver = bomb candidate if pickup holds
```

## B4. MTN Y Post — Trips TE Flex (MAN MIDDLE + CHECKDOWN)
```
STOCK READ: TE sharp post (man separator) → RB speed flat (YAC)

vs MAN: post wins
vs PRESSURE: flat is hot — ball out
vs ZONE: post between levels or dump flat
```

## B5. Drive HB Under — Bunch X Nasty (MAN/ZONE LAYER)
```
KEY: RB speed-in + solo-side short corner
READ: first open of RB in / short corner / drive traffic

Use when they press Bunch and sit deep.
```

## B6. X Cross — Bunch X Nasty (HB CRAB)
```
KEY: HB crab route = consistent separator vs man AND zone
READ: crab first, then cross traffic

This is a money checkdown that good players spam until you respect it.
```

## B7. Elitee Charlotte Crossers — Gun Bunch (ZONE)
```
SETUP:
  Leave R1 on STOCK crosser (shallower = harder to switch-stick)
  Streak Square
  Drag X
  Return route on Circle

READ:
  1) RB flat (almost instant — throw now for RAC)
  2) Zones sink → return route
  3) Zones bite → crosser sits behind them

Put it away vs pure man — audible to Drive / Shot Fake Cross / X Cross instead.
```


## B10. Y Curl — Gun Bunch

# PART D — BEATING WHAT THEY’RE ACTUALLY RUNNING

## D1. Mid Blitz / Nickel Man Heat (SportsGamersOnline)
```
1. LT/L2 → Y/Triangle → Y/Triangle again = IGNORE USER (oline ignore wig-out FS)
2. Put receivers to WIDE side, RB opposite — if you block RB, user has farther travel
3. Block 6 when they send 6 — but leave a HOT (flat/drag/slant)
4. Motion/flip vs safeties that walked down — they often WON’T travel (exploit)
5. Structure stress: Bunch Quads Offset / all-to-one-side leaves corner+safety with nobody
6. Playmaker deep: max protect (L2 + RS up) + 2 deep routes → after snap flick RS to break man
```

## D2. Cover 0 / Mug / Double Mug
```
HOT answers already in audibles: Shot Fake Cross, MTN Y Post flat, Crossers RB flat, Drive checkdowns
Ball out on break. Late = sack/INT.
If they guess wrong: Draw / Power I.
```

## D3. Cover 3
```
Cross Wheels wheel, Trips seam, Dash Flood, Verts HB Seam
```

## D4. Cover 2 / Tampa
```
Cross Wheels wheel (cloud doesn’t take it), Verticals Texas high-low, HB flats
```

## D5. Cover 4 / Match
```
Cross Wheels (breaks match), Crossers, Mesh traffic from Bunch
```

## D6. Man Press
```
Bunch rubs, Shot Fake Cross, zig/whip/return (unbumpable returns), TE/RB wheels (hard to bump), crab
Throw on the BREAK not after you “see” open.
Lead away from defender. Back-shoulder: LT + aim to back shoulder (classic/revamped).
```

## D7. Soft Zone / Prevent / Drop-8
```
Draw, Alert Bubble, screens, sit routes — do not force deep
```
