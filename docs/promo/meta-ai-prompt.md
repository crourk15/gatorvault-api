# Meta AI prompts — Open the Vault (restriction-safe)

Paste these into **Meta AI** (Ads Manager creative / Meta AI image). Built from prior agent notes: avoid UF trademark hits and “priceless” copy so ads are less likely to get restricted or rejected.

## Hard rules (always include)

- Brand hero: **GatorVault** (large, dominant)
- App listing name (caption only): **Gator Vault Insider**
- Destination: App Store ID `6783848215` / search “Gator Vault Insider”
- Colors OK: Florida orange `#FA4616` and blue `#0021A5` as accents only
- **NO** University of Florida / Florida Gators alligator head, UF seal, helmet logo, or any trademark marks
- **NO** word “priceless” (or Mastercard-style “priceless” phrasing)
- **NO** fake Apple buttons — use the official “Download on the App Store” badge look, unmodified, or plain text “Download on the App Store”
- Do **not** imply official university affiliation or endorsement
- Make it a **GatorVault** ad, not an Apple ad and not a UF ad
